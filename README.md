# EuropeTracker

A daily morning brief, published at about 06:15 Taipei, that gauges the risk of the Russia-Ukraine war
spilling into Europe. It covers:

- a seven-rung spillover ladder
- seven spillover pathways
- frontline-country scores
- an incident database since 2022
- Ukraine's deep strikes into Russia
- warning indicators
- scored forecasts
